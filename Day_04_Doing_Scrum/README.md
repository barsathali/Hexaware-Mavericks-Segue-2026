# Day 4 — Doing Scrum: Sprint Simulation

This pack covers all three scenarios in the Day 4 assignment:
1. Digital Wallet Application — Mid-Sprint Change
2. Airline Web Check-in — Blocked Dependency
3. E-Learning Platform — Scope Change Handling

## Files
Each set folder contains:
- `report.md` — completed written responses
- `sprint_backlog.csv` — story backlog
- relevant calculation/log CSVs
- `board_mockup.png` — illustrative Jira-style board image
- Set 1 also includes a sprint burndown chart

## Important screenshot note
The PNG board images are **illustrative mock-ups**, not screenshots from a real Jira account. They are included as visual evidence of the proposed board layout. If the instructor specifically requires genuine Jira screenshots, create/import the issues in your Jira account and capture the live board.

## Data assumptions
The uploaded assignment document refers to supplied backlogs and completed-points tables for Set 1 and Set 3, but those tables were not present in the uploaded DOCX. Therefore, the CSV datasets and related calculations in this pack are clearly treated as sample/illustrative data. Replace them if a separate official data sheet is provided.

## Open in VS Code
Open this folder in VS Code. Read each `report.md` and open the CSV/PNG files in the corresponding set folder.
