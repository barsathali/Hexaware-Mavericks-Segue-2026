# Python Track – Day 3: Agile and Scrum

This package covers the three Day 3 scenarios from the assignment:
1. Online Grocery Delivery Application
2. Insurance Claims Portal
3. Hospital Appointment Booking Application

Each set folder contains:
- `report.md` – assignment write-up and required Scrum/Agile content
- `backlog.csv` – backlog records with priorities and story points
- `jira_import.csv` – CSV formatted for Jira issue import
- `README.md` – deliverable summary

## Jira import checklist
1. Create a Scrum project for the relevant scenario.
2. Open Jira's CSV import feature (administrator/import permissions may be required).
3. Select `jira_import.csv`.
4. Map Issue Type, Summary, Description, Priority, Story Points and Epic Link.
5. Import epics first or ensure the importer creates epics and resolves Epic Link relationships.
6. Configure columns: To Do, In Progress, In Review, Done.
7. Attach the Definition of Done (and DoR where included) from `report.md`.
8. Capture a genuine screenshot/export of the populated backlog and board.

Note: the files prepare all deliverables and import data. A live Jira project/board and screenshot must be created from your Jira account.
