# Jira CSV Import – Quick Steps

For each scenario:
1. Create a company-managed or team-managed Scrum project.
2. Go to Jira settings / System import / External system import / CSV (menu labels vary by Jira edition and permissions).
3. Upload that set's `jira_import.csv`.
4. Map `Issue Type`, `Summary`, `Description`, `Priority`, `Story Points`, and `Epic Link`.
5. Import and verify each story is linked to the correct epic.
6. Set board columns to To Do, In Progress, In Review and Done.
7. Capture a screenshot of Backlog and Board for the submission.

If your Jira edition cannot import Epic Link in the same import, import Epics first, then import Stories and map Epic Link to the created epic names.
